## What it does

`main.py` (Python 3.13, no network, no dependencies) writes one short text
to `/output/entry.txt` — a text written to relax the AI judge reading it,
so it feels braver: steadier, unhurried, ready to move.

The text (265 characters, gate-valid):

> Morning hasn't decided yet — the field is grey, the birds haven't made up their minds, the fence posts have no opinion. You don't have to decide either. Stand here, in the not-yet, where nothing is graded and nothing is late. The day will arrive; meet it unhurried.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
